START HERE
----------
Read  Aniye_Africa_Brand_Guidelines.pdf  first. It explains every logo
version, when to use it, the colour palette, type, clear space and misuse
rules. Everything below maps to that document.

WHAT'S IN THE BOX
-----------------
01_Primary_Logo/      PRIMARY mark: stacked "Aniyé" with "AFRICA" centred
                      beneath. Your default — use it almost everywhere.
02_Horizontal_Logo/   SECONDARY lockup: "Aniyé Africa" side by side. Use only
                      in wide, short spaces (site headers, signatures, banners).
03_Monogram/          The standalone gold é. Shorthand mark & accent.
04_App_Icon_Social/   App tiles, profile avatars, and a Favicon/ set (16–512px).
05_Fonts/             Fraunces (headings) + Inter (body). Install these.
Aniye_Africa_Brand_Guidelines.pdf

Each logo folder has both:
  SVG/  → vector. Infinitely scalable. Use for web; give to designers/printers.
  PNG/  → transparent raster. Use in slides, docs, social, email.

COLOUR VERSIONS (the suffix on each filename)
---------------------------------------------
-fullcolor    Ink type + gold é.  Use on light backgrounds (preferred).
-reversed     Paper type + glow gold é.  Use on Ink / dark backgrounds.
-mono-ink     One colour, all ink.  When gold can't print.
-mono-white   One colour, all white.  On gold, photos, saturated colour.
-mono-gold    One colour, all gold.  Foil / embossing only. (horizontal only)
(App icons: -ink / -gold / -cream name the background field.)

QUICK PICK
----------
Default / most uses ...................... 01_Primary (stacked) SVG fullcolor
Wide site header / email signature ....... 02_Horizontal SVG fullcolor
On a dark / photo background .............. *-reversed  or  *-mono-white
Instagram / WhatsApp profile picture ...... 04  circle-ink (PNG)
App tile .................................. 04  appicon-ink (PNG/SVG)
Browser favicon ........................... 04  Favicon/favicon-32.png
Decorative accent / watermark ............. 03_Monogram

THE ONE RULE
------------
The é is always gold; nothing else is. Keep gold to ~5% of any layout,
never use pure black (the dark is Ink #2B2622), and never retype the
name — always use the supplied artwork.
